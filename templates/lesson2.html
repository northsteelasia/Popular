Lesson 2 — Variables

Variables allow you to store information in Python.

Creating a Variable

Here we store a person's name: 

name = "Paul"

The variable name now contains the text Paul.

Using a Variable

name = "Paul"

print(name)

The output is:

Paul

Numbers

Variables can also store numbers. 

age = 20

print(age)

The output is:

20

Exercise

Create two variables:

  • Your name
  • Your age

Then use print() to display them.
